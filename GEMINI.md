# WorldView — instructions for Gemini / Antigravity

Read `HANDOFF.md` first, then `AGENTS.md`. They describe the project, how to run it, the code map
and the project rules you must follow (keyless data only; honest User-Agent, never get around bot
checks or rate limits; label AI output; nothing personal in git and credit "akshng" only;
typecheck + lint + tests + build green before finishing).

This app uses Next.js 16 with breaking changes from older versions: read the relevant guide in
`node_modules/next/dist/docs/` before writing Next.js code.
